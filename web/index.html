设备设置

STUDIO CONNECTION

连接 NoteFall Core

乐谱、曲库和练习在本机运行；Core 只处理钢琴 USB 与灯带。

灯带校准

先点击“测试中央 C”。如果亮点偏左或偏右，只调像素偏移；如果整条方向相反，打开反向。

逐键微调

只有个别键仍偏位时才使用。每步移动一个灯珠；先调全局偏移，再从中央 C 向两端检查。

快速复核时从左到右弹一遍：位置正确就继续；只有偏位的键才点上面的方向按钮。无需逐键填写或记录数字。

校准保存在ESP32；建议完成后另存一份备份。

加入家庭 Wi-Fi（可选）

只能在连接 NoteFall-88 热点时修改；还需在下方“设备维护”输入当前热点密码。

设备维护

热点内自动允许练习控制；从家庭 Wi-Fi 打开时，灯光、校准和 MIDI OUT 默认只读，需用当前热点密码解锁本标签页。更新仍只允许从 NoteFall-88 热点发起。密码不会写入曲库、练习记录或导出文件。
