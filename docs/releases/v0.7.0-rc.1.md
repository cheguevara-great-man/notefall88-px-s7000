# NoteFall 88 v0.7.0-rc.1

这是首个可下载的数字工程候选版，目标硬件为乐鑫官方 `ESP32-S3-DevKitC-1 N8R8`、PX-S7000 与单条 5V APA102C/SK9822 灯带。

## 下载哪个文件

- 全新开发板：下载 `notefall88-factory-v0.7.0-rc.1.zip`，完整解压后按其中 `FLASHING.md` 操作。单文件镜像和烧录脚本都会先做 SHA-256 校验。
- 已经运行 NoteFall：下载 `notefall88-update-v0.7.0-rc.1.zip`，在设备热点的维护页分别上传其中固件与 LittleFS 镜像。
- 找淘宝代做线束或打印控制盒：下载 `notefall88-manufacturing-v0.7.0-rc.1.zip`。

不要把 ZIP 外的 JSON 清单当成固件，也不要把任意 `.bin` 猜测写到地址 `0x0`。

## 本候选版包含

- PX-S7000 → ESP32-S3 原生双向 USB-MIDI，实体按键到灯带的本地实时路径不经过 Wi-Fi；
- 176 像素单灯带、真实琴键中心映射、逐键校准和断线熄灯；
- MIDI、MusicXML/XML/MXL、五线谱与瀑布流、三种练习模式、循环/变速/移调/左右手；
- 曲库、备份、演奏录制与 MIDI 导出、练习分析和自适应建议；
- SoftAP/STA 分权、启动期控制令牌、双槽 OTA、诊断与 13 项安装向导；
- 参数化控制盒、BOM、逐线线束表、功耗/压降预算和可重复制造包。

## 验证边界

G0 数字门禁已经通过，包括固件、LittleFS、机械生成、自动测试、MusicXML 语料和 Chromium/WebKit 浏览器回归。本版本仍是 **Pre-release**：尚未完成用户实物上的 G1 台架和 G2 PX-S7000 装琴门禁，因此不能称为硬件验证版或量产版。

首次上电请保持钢琴和灯带断开，只连接开发板 UART 口完成烧录；随后严格按《第一次制作》和《完整测试流程》逐级接线。
