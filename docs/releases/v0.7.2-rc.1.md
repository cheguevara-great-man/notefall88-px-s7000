# NoteFall 88 v0.7.2-rc.1

这是第三个数字工程候选版，目标硬件为乐鑫官方 `ESP32-S3-DevKitC-1 N8R8`、PX-S7000 与单条 5V APA102C/SK9822 灯带。它在 v0.7.1-rc.1 的 USB-MIDI 包级验证之上，进一步验证决定实机能否枚举成功的配置描述符和端点选择路径。

## 下载哪个文件

- 全新开发板：下载 `notefall88-factory-v0.7.2-rc.1.zip`，完整解压后按其中 `FLASHING.md` 操作；脚本会先验证板型、镜像大小与 SHA-256。
- 已经运行 NoteFall：下载 `notefall88-update-v0.7.2-rc.1.zip`，在设备热点的维护页分别上传其中固件与 LittleFS 镜像。
- 找淘宝代做线束或打印控制盒：下载 `notefall88-manufacturing-v0.7.2-rc.1.zip`。

不要把 ZIP 外的 JSON 清单当成固件，也不要把任意 `.bin` 猜测写到地址 `0x0`。

## 相比 v0.7.1-rc.1

- USB Audio/MIDIStreaming 配置描述符选择器成为固件实际共用的纯 C++ 核心，不再只能靠 ESP32 编译间接证明；
- 主机测试覆盖双向 MIDI、只有 IN、非 MIDI 接口在前、多个候选接口、接口 claim 后继续搜索、零长度、截断、EP0、非 Bulk、过小及非 4 字节对齐包长；
- 畸形描述符会明确失败，不再把不可信的端点包长猜成 64 字节；
- MIDI OUT 缺失仍允许基本目标灯运行，并明确降级为无伴奏 Follow Me；
- 网页显示不含凭据的 USB 最近枚举/传输原因，该原因也进入验收报告；
- 自动门禁提升至 52 项 Python/工程测试和 123 项 Web 测试，并继续通过 Chromium、WebKit、固件、LittleFS、机械及发布包检查。

## 验证边界

G0 数字门禁已经通过。本版本仍是 **Pre-release**：尚未完成用户实物上的 G1 台架和 G2 PX-S7000 装琴门禁，因此不能称为硬件验证版或量产版。

首次上电请保持钢琴和灯带断开，只连接开发板 UART 口完成烧录；随后严格按《第一次制作》和《完整测试流程》逐级接线。
