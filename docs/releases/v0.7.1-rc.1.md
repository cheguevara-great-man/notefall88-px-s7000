# NoteFall 88 v0.7.1-rc.1

这是第二个数字工程候选版，目标硬件仍为乐鑫官方 `ESP32-S3-DevKitC-1 N8R8`、PX-S7000 与单条 5V APA102C/SK9822 灯带。它在 v0.7.0-rc.1 的功能基线上重点提高 USB-MIDI 实时核心的可验证性和现场诊断精度。

## 下载哪个文件

- 全新开发板：下载 `notefall88-factory-v0.7.1-rc.1.zip`，完整解压后按其中 `FLASHING.md` 操作；脚本会先验证板型、镜像大小与 SHA-256。
- 已经运行 NoteFall：下载 `notefall88-update-v0.7.1-rc.1.zip`，在设备热点的维护页分别上传其中固件与 LittleFS 镜像。
- 找淘宝代做线束或打印控制盒：下载 `notefall88-manufacturing-v0.7.1-rc.1.zip`。

不要把 ZIP 外的 JSON 清单当成固件，也不要把任意 `.bin` 猜测写到地址 `0x0`。

## 相比 v0.7.0-rc.1

- USB-MIDI 通道消息编码、解码、CC88 高分辨率力度、毫秒计时回绕与真实 88 键像素映射已抽成固件实际共用的纯 C++ 核心；
- CI 使用严格警告选项编译并执行该核心，穷举全部 16 通道和 0x8–0xE 通道消息的边界组合，再由 Xtensa 工具链编入实际固件；
- USB 诊断区分输入队列丢包、CIN/status/data 真正坏包和底层传输错误；
- 合法但当前不消费的 SysEx、MIDI 时钟和 Active Sensing 会被安全忽略，不会被误判为硬件故障；
- 安装向导将上述三类输入错误合并为不可点击绕过的零错误验收证据；
- 自动门禁提升至 51 项 Python/工程测试和 123 项 Web 测试，并继续通过 Chromium、WebKit、固件、LittleFS、机械及发布包检查。

## 验证边界

G0 数字门禁已经通过。本版本仍是 **Pre-release**：尚未完成用户实物上的 G1 台架和 G2 PX-S7000 装琴门禁，因此不能称为硬件验证版或量产版。

首次上电请保持钢琴和灯带断开，只连接开发板 UART 口完成烧录；随后严格按《第一次制作》和《完整测试流程》逐级接线。
