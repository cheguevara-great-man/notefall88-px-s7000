# 竞争能力与领先性审计

> 固定快照：2026-08-05。比较对象与源码提交见 [开源项目技术调研](open-source-review.md)。这里的“领先”仅指“PX-S7000 单条实体灯带练习系统”这一目标，不把 VST、视频导出或通用吉他谱转换等旁支功能硬算成钢琴灯带能力。

## 可审计结论

NoteFall 88 已经不是“ESP32 点亮一条灯带”的演示，而是当前对标项目中唯一同时具备下列组合的开源工程：

1. PX-S7000 USB-B → ESP32-S3 原生双向 USB-MIDI，按键反馈不经过手机、浏览器或 Wi-Fi；同批事件先完成 SPI 灯帧、再广播网页，并自测 USB 回调到 SPI 完成延迟；
2. APA102/SK9822 硬件时钟灯带、5 V 电平转换、双端注电、固件亮度硬上限和故障熄灯；
3. MIDI + MusicXML/XML/MXL、五线谱 + 瀑布流、真实反复/结尾/D.C./D.S./Fine/Coda 播放顺序；
4. Realtime、Wait for Me、Follow Me、左右手、25%–200% 五个百分点步进变速、移调、A–B、谱面节拍器和预备拍；
5. 双向 Follow Me 直接调用 PX-S7000 音源，并具备排程、疑似输出镜像诊断、多页面互斥和 16 通道急停；不会用不可区分的时间启发式删除真实琴键输入；
6. 逐音时序/力度分析、持久历史、难点键与可解释的自适应片段/声部/速度建议；
7. IndexedDB 曲库、去重、校验备份、保留真实 Note Off、CC88 高分辨率力度与连续 CC64/66/67 的通道化演奏录制、标准 MIDI 导出及长录制内存上限；
8. 逐键灯位校准、设备诊断、有自动证据的安装向导、SoftAP 限定认证 OTA，以及 STA 默认只读/会话再认证控制面；
9. 参数化键位/CAD、可采购 BOM、逐引脚线束表、功耗/压降计算、可重复制造包和跨层 CI。

这是“组合领先”，不是声称每个不相关功能都最多。Piano Trainer Studio 仍领先于 MuseScore/Guitar Pro 浏览器转换；Piano-LED-Visualizer 仍有成熟的树莓派/Linux 部署经验；Openthesia 仍领先于桌面 VST、音频和视频工作流。这些能力不进入 NoteFall 的琴前核心链路，必要时应由未来 Studio 层承载。

## 性能与资源预算

| 指标 | 数字门禁 | 当前计算/构建结果 |
|---|---:|---:|
| 176 像素 SPI 刷新 | `< 1 ms` | 生成测试通过 |
| 键中心到主像素理论误差 | `≤ 3.472 mm` | `3.444 mm` |
| 固件亮度上限设计电流 | `< 3 A × 80%` | `2.013 A` |
| 20 AWG 最坏支路压降 | `≤ 5%` | `1.45%` |
| 5 V / 5 A 电源利用率 | `< 60%` | `40.3%` |
| 固件 RAM / Flash | 保持足够诊断裕量 | `17.2% / 34.8%` |
| 嵌入网页压缩资源 | `< 500 KiB` | `418465 B`（约 `408.7 KiB`） |
| 自动测试 | Python + Web 全通过 | `62 + 148`（共 210 项，2026-08-10 本机复跑）；Python 门禁会以 `-Wall -Wextra -Werror -pedantic` 编译并实际执行固件共用的纯 C++ MIDI 核心，覆盖全部 16 通道和 0x8–0xE 通道消息、CIN/状态坏包、合法系统消息忽略、CC88 一次性通道隔离、毫秒回绕、真实 88 键正反映射，以及 USB Audio/MIDIStreaming 双向/仅输入/多接口/截断/畸形端点描述符；另有单文件首刷镜像偏移/分区上限/篡改拒绝/可重复性、发布标签与固件/文档版本一致性、工作流防误发布与生成检查只读性门禁。非 DOM/渲染适配器 Web 产品模块覆盖率 S/B/F/L 为 91.52/81.15/90.56/95.27%，CI 门限 85/75/85/90%；固定 Playwright CLI 在 Chromium + WebKit 中对手机/桌面/3:2 平板、全屏沉浸降级、抽屉、STA 解锁密码边界、文件选择器、OSMD、小节重开，以及 48 小节/192 音符合成长谱的自动翻谱做真浏览器回归并上传证据；另有 1016 文件 MusicXML/MXL 固定语料审计（1012 解析、4 预期拒绝、0 意外异常），以及 6 首/2638 音符对 music21 的独立内容交叉验证（最大起音差 0.109 ms） |

计算值不能代替实物：LED 克隆批次的真实电流、最远端电压、接头温升和 USB 端点只能在装机后测量。

## 领先性成立的边界

- **数字工程领先：** 源码、协议、安全、可重复生成、发布包和测试门禁全部通过后成立。
- **目标内产品领先：** 还需一台 PX-S7000 完成 [实机验收](testing.md)，特别是 USB 双向端点、88 键、30 分钟温升、断线急停和 120 fps 延迟。
- **量产领先：** 还需至少一套由第三方按 `harness.csv` 制作的线束与一个 PETG 控制盒通过装配反馈；在此之前只能称 release candidate，不能虚称量产验证。

## 明确不塞进 Core 的功能

- MuseScore/Guitar Pro 转换：可由未来 NoteFall Studio 或桌面 MuseScore 转换，不让大体积 WASM 成为琴前设备启动条件。
- VST/SoundFont/视频录制：PX-S7000 自己发声，手机负责练习，不让音频工作站职责污染实时灯光链路。
- 云账号、订阅和远程遥测：项目离线可用，练习历史默认只留本机。

这些不是“没做完的核心功能”，而是经过目标、可靠性、许可证和移动端资源边界审计后的分层决定。
