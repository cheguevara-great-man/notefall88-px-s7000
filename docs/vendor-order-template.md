# 发给线束/灯带卖家的代工消息

请按附件 `harness.csv` 和 `wiring-harness.svg` 制作一套 5V 低压线束，并完成灯带端焊接。用途是数码钢琴灯带，不接市电裸线。

必须满足：

1. 灯带：APA102C 或 SK9822，5V、144灯/m、黑色PCB、非防水，从连续 2m 成品裁 176 灯；箭头从 DIN/CIN 指向远端。
2. 灯带输入：Micro-Fit 3.0 兼容 4P，Pin1 红 5V、Pin2 黑 GND、Pin3 绿 DATA、Pin4 蓝 CLOCK；供电侧必须使用凹端子。
3. 灯带远端：只用 XT30 并联注入 5V/GND，不连接末端 DATA/CLOCK；供电侧必须使用凹端子。
4. 首尾各焊 1000µF/10V 电容，正极接 5V，带条纹负极接 GND；焊点热缩绝缘并做扎带应力释放。
5. DATA、CLOCK 各串 100Ω 电阻，靠近 74AHCT125 输出端；不要互换 DATA/CLOCK。
6. H5：保险后 5V/GND 到 ESP32 `USB-to-UART` 的 Micro-USB 公头，只接 VBUS/GND。
7. H7：保险后 5V/GND 到 OTG Y 线第三供电口的 Micro-USB 公头，只接 VBUS/GND。H5、H7 是两根独立支路，不能合并掉其中一根。
8. 5V 总入口后 100mm 内串 3A 保险丝；红黑主电源线 20AWG，H5/H7/模块供电不细于24AWG，信号线26AWG。
9. 交货前逐线蜂鸣，确认 5V-GND 不短路、DATA/CLOCK 不互换、连接器极性正确；提供万用表检查照片。
10. 所有焊点和裸铜双层热缩或等效绝缘；线缆轻拉 10N 不脱落。

如附件与口头描述不一致，请先暂停并按附件逐项提问，不要自行改针脚、线色、保险丝或连接器方向。
