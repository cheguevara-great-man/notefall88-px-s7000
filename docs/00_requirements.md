# 需求基线与验收口径

## 目标

在 Casio PX-S7000 上提供无需永久改造的“实体下落音符”提示。系统显示乐谱中尚未到达的音符，并让光点随时间从远排移动到靠近琴键的当前排。电脑负责乐谱、节拍和交互，ESP32-S3 负责确定性输出、亮度上限与失效熄灯。

## 必须满足

| 类别 | 需求 | 验收方法 |
|---|---|---|
| 无损 | 不钻孔，不拆琴，不把胶粘剂贴到琴漆或琴键 | 安装前后照片；移除后斜光检查无印痕/残胶 |
| 演奏 | 不进入正常手指扫掠空间，不阻挡黑键后段 | 15 分钟音阶、琶音、强奏测试，无碰手 |
| 指示 | 12 个半音在一八度内均有唯一主像素 | 自动映射测试；暗室/室内目视辨识 |
| 时间 | 至少 4 个离散未来位置，方向直观 | 60 BPM 单音阶录像，位置无倒退 |
| 延迟 | 电脑帧到灯光的稳态延迟目标 < 25 ms | 高帧率录像或逻辑分析仪 |
| 安全 | 单点通信故障后 1 s 内熄灯；导线和接头无危险温升 | 拔 USB、卡住电脑程序、30 分钟温升测试 |
| 可制造 | 首件适合 220 × 220 mm FDM 打印平台 | 所有 V0 STL 包络自动检查 |
| 模块化 | 灯带、光栅、柔光片、底座可独立更换 | M3 紧固件拆装 5 次无损 |

## 明确不做（V0）

- 不把灯阵当作琴键按下检测器；当前音符来自乐谱时间轴或外部 MIDI。
- 不接入钢琴内部电源，不改动原厂 USB/踏板/音频电路。
- 不追求阳光直射下可视；目标环境为普通室内照明。
- 不在未取得实测尺寸前打印 1.2 m 全长结构。
- 不依赖无线链路保证时序；V0 使用 USB 串口。

## 设计载荷和环境假设

- 室内 10–35 °C，相对湿度 20–80%，无凝露。
- 设备不承担谱架、平板或手臂载荷；意外按压设计目标 20 N 不接触琴键。
- V0 只使用额定阻燃外壳的 5 V 电源，交流侧不进行任何自制接线。
- 初始琴键几何采用 164.5 mm/八度、23.5 mm/白键，仅用于生成首件；真实值通过跨 7 个白键测量校正。

## 成功条件

V0 通过并不等于全尺寸设计完成。只有以下数据同时获得，才进入一八度演奏原型：串光评分、最佳柔光方案、室内可用亮度、30 分钟峰值温升、琴体实测参数和弹奏干涉结果。
