## 当前发布判定

- G0 数字工程：通过，允许生成 release candidate；
- G1 台架：缺 ESP32、最终线束和灯带实测；
- G2 装琴：缺 PX-S7000 USB 枚举、88 键、温升、延迟、眩光与无损安装实测；
- 因此 PR 保持草稿，不能把当前版本称为“硬件验证版”或“量产验证版”。

详细门禁与阈值见 [发布候选门禁](release-readiness.md) 和 [完整测试流程](testing.md)。
