# 本机到货验收清单

> 当前状态：硬件已下单、尚未到货。本清单只要求清点和断电测量；未到“允许上电”标记前，不连接 5 V 电源。
> 在本清单第 5 节全部满足前，不得给灯带或钢琴 USB 链路上电。

## 0. 先不要做

- 不要剪灯带，不要贴琴，不要给灯带上电。
- 不要仅凭红黑绿蓝线色判断引脚；先看灯带焊盘标识和箭头，再用万用表确认。
- 商家已经确认所购 KF301‑2P/3P 具体款可以共点；到货前先不假定共点方向，收到后用通断档把每个孔的关系画出来。
- 商品若带共点底板/金属连接结构，可在复核后直接使用；若收到的是只有 PCB 直脚的标准裸端子，则仍需焊到小板。以到货结构为准，不凭型号名称争论。
- 不要用杜邦线承载灯带电流，不要把裸 DIP 芯片直接装入最终控制盒。
- 不要把两只不同电源同时接入 ESP32、Y 线或灯带。

## 1. 拍照留证但不要上传个人信息

只拍物品、标签、接口和焊盘近照；画面中不要出现订单、快递面单、地址、电话、付款页、银行卡或聊天账号。建议照片命名：

- `power-label.jpg`
- `strip-input.jpg`、`strip-output.jpg`
- `y-cable-ports.jpg`
- `esp32-label-and-ports.jpg`
- `h5-h7-wire-ends.jpg`
- `level-shifter-parts.jpg`

这些照片只在需要诊断时提供；仓库默认不收录私人实物照片。

## 2. 按台账清点

逐行打开 [as-purchased.csv](as-purchased.csv)，把“已买未到”核成实物。数量、型号或接口不符时先单独放置，不尝试“能插就插”。重点确认：

- ESP32 丝印为官方 `ESP32-S3-DevKitC-1`，模组为 `N8R8`；
- 灯带为 `SK9822 / 5V / 144 px/m / 黑色 PCB / 非防水`；
- 电源铭牌为 `5 V / 5 A`，DC 插头与 DC015 匹配；
- 芯片完整料号含 `74AHCT125`，不是 `74HC125`、TXS0108E 或 BSS138；
- Y 线确有 Micro-USB 公头、USB-A 母口、Micro-USB 供电口三个接口；
- 打印机线是 USB-A 公到 USB-B 公，接钢琴方形 `USB TO HOST`。

## 3. 断电电气检查

1. 万用表表笔短接应蜂鸣；分开不蜂鸣。
2. 按商家说明拼好 KF301‑2P/3P，在端子完全断电且未接其他器件时逐孔蜂鸣，画一张“哪些孔互通”的小图。预定作同一 5V 或 GND 节点的孔必须全部互通；5V 组与 GND 组必须完全不通。结果与商家说明不符就停用并联系商家。
3. 保险丝装入时保险座两端导通，取下时断开。
4. 100 Ω 电阻逐只测得约 100 Ω；电解电容确认负极条纹，暂不测带电容量。
5. 打印机线的 USB 外壳无松动；不要用通断档盲碰相邻 USB 针脚。
6. 灯带输入端必须能看到 `DI/DIN`、`CI/CIN` 或箭头起点；输出端应是箭头终点。把实际焊盘文字和线色写进验收记录，线色与文档冲突时以焊盘为准。
7. 两根 Micro-USB 供电线在接入任何设备前，确认哪根裸线到 VBUS、哪根到 GND；若不能可靠查明，停止使用并更换明确标注的供电线。

## 4. 到货后最小补件判定

以下不是让用户现在重新采购，而是根据实物决定：

- **0.1 µF（100 nF）陶瓷电容：必需。** 裸 74AHCT125N 与成品模块不同，必须在 14 脚 VCC 和 7 脚 GND 附近去耦；如果现有电子套件没有，只补这一只或小包。
- **KF301 配电形态：到货判定。** 商家已确认这批可以共点；蜂鸣结果符合说明就直接作为 5 V/GND 公共节点，不补买端子。若实物只有待焊 PCB 直脚，则把它与 74AHCT125N、100 Ω 电阻和 0.1 µF 去耦一起装到小板，不临场悬空搭接。
- **绝缘与应力释放：条件必需。** 若电阻、电容、DC015、保险座或盒体开口存在裸导体/磨线风险，补热缩管、护边或扎带后才允许上电。
- **接触式温度计：G1 前必需，可借。** 不影响清点，但没有温升数据不能通过 G1。

## 5. 允许进入 G1 的条件

必须同时满足：

- [ ] `as-purchased.csv` 每个最终件完成型号与数量核对；
- [ ] 灯带方向、像素数量和头尾线定义已经记录；
- [ ] 电源、DC015 与保险的规格匹配；
- [ ] H5/H7 的 VBUS/GND 已能逐线确认；
- [ ] 74AHCT125N 有 0.1 µF 就近去耦方案，未使用通道不会悬空；
- [ ] KF301 的实物共点图已记录，5 V 组内部全通、GND 组内部全通、两组之间不通；
- [ ] 所有裸导体有绝缘方案，所有重线有应力释放；
- [ ] 万用表工作正常。

满足后，按 [上电、校准与验收](../testing.md) 的 A→B 顺序进入 G1：先烧录并只验证 ESP32，再验证 USB，最后才接灯带。任何过热、异味、闪烁、随机重启或 USB 反复掉线都立即断电。
