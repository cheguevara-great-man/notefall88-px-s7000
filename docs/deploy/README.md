# 本机部署资料

本目录记录用户这台 PX-S7000 的实际采购与到货验收，不替代仓库的通用制造基线。

## 当前状态

- 采购日期：2026-08-08
- 状态：已下单，尚未到货
- 实际路线：SK9822 裸线灯带 + 商家确认可共点的 KF301‑2P/3P 配电端子 + ESP32-S3 原生 USB Host
- 已知差异：本机没有按通用 BOM 购买 Micro-Fit、XT30 或成品 74AHCT125 模块；KF301 共点能力以商家确认和到货通断复核为准，74AHCT125N 裸芯片仍需先上面包板并最终焊成可靠小板
- 下一门禁：到货清点与断电检查；在通过前不得给灯带或钢琴 USB 链路上电
