# 引导式安装与实机验收

设备网页右上角的“硬件尚未验收”不是装饰状态。安装向导把必须由人确认的物理事实与能由设备直接观测的数字证据分开；缺任何强制项都不能生成“已完成”状态。

## 证据模型

| 类别 | 项目 | 来源 |
|---|---|---|
| 断电人工 | 5V-GND、DATA/CLOCK 万用表检查 | 用户在断电实物上确认 |
| 断电人工 | 3–5 A 保险丝 | 用户确认线束 |
| 断电人工 | 灯带独立 5 V 供电、与 ESP32 共地 | 用户确认接线 |
| 机械人工 | 琴体接触材料无永久胶/硬边 | 用户确认材料 |
| 自动 | 兼容协议的 ESP WebSocket 状态 | 设备状态帧 |
| 自动 | PX-S7000 枚举、VID/PID、MIDI IN 端点 | ESP32 原生 USB Host |
| 自动 | 钢琴实际中央 C Note On | USB MIDI 事件，不接受页面按钮代替 |
| 灯位人工 | A0、C4、C8 三点亮点对应 | ESP 发测试灯，用户看实物确认 |
| 机械人工 | 强奏/谱架/线缆扰动后无触键、位移、异响 | 用户完成实物试验 |

MIDI OUT 是跟随伴奏能力，不是基本目标灯的阻塞条件；缺失时报告保留“设备未提供/尚未观测”，产品明确降级。USB 输入错误大于 0 会阻止完成，不能靠勾选覆盖。

## 状态、升级与报告

完成状态保存在浏览器本地并记录当时固件版本。检测到固件版本变化后，物理接线勾选保留，但完成标志、USB 枚举和中央 C 证据失效；新固件必须重新观测后再完成。

任何时候都能导出版本 1 JSON，包含：

- 完成与否和缺失项目；
- 固件/协议；
- VID/PID、IN/OUT 端点；
- 已观测输入包、错误数；
- 所有人工作业布尔项和完成时间。

报告不含热点/家庭 Wi-Fi 密码、曲库、演奏历史或原始乐谱。它是可审计的安装记录，不是加密签名或第三方认证；用户仍能手工修改浏览器存储，所以量产质检若需要防篡改，应由工厂工具签署序列号报告。

## 通过后的下一步

引导完成只证明基础接线、USB、三个灯位和机械干涉已检查。完整发布仍需执行 [上电、校准与验收](testing.md) 中的 88 键映射、和弦、断线、跟随伴奏、温升和 120 fps 延迟项目。
