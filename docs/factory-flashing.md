# 全新开发板首次烧录

本 ZIP 只适用于乐鑫官方 `ESP32-S3-DevKitC-1 N8R8`。它会清除目标开发板的全部 Flash，并一次写入引导程序、分区表、固件和 NoteFall 网页；不要用于其他 ESP32 型号或已有重要数据的开发板。

## Windows 操作

1. 完整解压 ZIP，不要直接在压缩软件预览窗口里运行脚本。
2. 暂时断开钢琴、灯带和外部 5V，只用可靠的数据线把开发板的 `UART` Micro-USB 口连接电脑。
3. 在设备管理器查看串口，例如 `COM5`。
4. 安装 Python 3.10 或更高版本，然后在解压目录打开 PowerShell：

```powershell
python -m pip install esptool==4.5.1
python flash_factory.py --port COM5
```

把 `COM5` 换成实际端口。脚本会先验证板型、文件大小和 SHA-256，再显示即将执行的命令；只有输入大写 `ERASE` 后才清除并写入。不要用 `--yes` 跳过首次确认。

## 烧录后

1. 等待开发板重启，手机搜索 `NoteFall-88` 热点。
2. 使用首次密码 `notefall88`，打开 `http://192.168.4.1`。
3. 立即在“灯带校准 → 设备维护”把默认密码改成至少 12 位的独有密码。
4. 再按仓库中的《第一次制作》和《完整测试流程》连接 H5/H7、Y 线、钢琴和灯带。

若脚本在写入前失败，不会改变设备；若写入中途断电，重新运行同一命令即可。脚本不自动猜串口，避免误擦除其他串口设备。
