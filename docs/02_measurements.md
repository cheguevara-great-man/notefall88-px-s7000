# PX-S7000 现场测量单

公开资料只能确认本体包络 1340 × 242 × 102 mm，无法可靠给出灯阵所需的局部截面。以下 8 项是进入“一八度演奏原型”前唯一需要用户现场完成的输入。不要拆琴。

## 工具

- 150 或 300 mm 钢直尺（毫米刻度）
- 两张硬卡片/银行卡，用作垂直基准
- 一叠普通打印纸（必要时测高度差）
- 美纹纸；只贴在直尺或打印件上，不贴琴漆
- 手机，开启 2× 镜头以减小广角变形

## M01–M08

| 编号 | 测量 | 方法 | 目标精度 |
|---|---|---|---|
| M01 | C4 左边缝到 C5 左边缝 | 直尺平放在白键前端，跨 7 个白键一次读数；不要逐键累加 | ±0.5 mm |
| M02 | A0 左边到 C8 右边总键宽 | 在白键前端测；若直尺不够，分段测并让每段跨完整八度 | ±2 mm |
| M03 | 键后基准线到最近控制件的可用深度 | 在左、中、右各测一次；从红毡前缘/白键后端的固定线到旋钮、屏幕或凸起前缘 | ±1 mm |
| M04 | 顶板到未按白键顶面的高度差 | 直尺跨在顶板，另一卡片竖在白键上读差；左、中、右各一次 | ±1 mm |
| M05 | 顶板前缘是否有台阶/圆角 | 侧面贴尺拍近照，尺与琴纵向平行 | 照片可判读 |
| M06 | 顶板横向平整度 | 直尺背光贴在候选安装区，拍左、中、右三张缝隙照 | 识别 >0.5 mm 缝隙 |
| M07 | 控制区横向禁入范围 | 从 A0 左边为 0，记录屏幕、旋钮、触摸环等每个障碍的左/右坐标 | ±3 mm |
| M08 | 演奏者视线 | 手机放在眼睛位置，保持常用坐姿，拍向键盘的一张照片，画面包含键后顶板 | 定性 |

## 必拍的 5 类照片

1. M01 直尺读数的正上方近照；
2. 模块候选区左、中、右三个侧截面，镜头高度与琴键齐平；
3. M03 三处深度读数的正上方照片；
4. M06 直尺背光照片；
5. M08 正常坐姿视角。

每张照片中都要同时出现直尺刻度和测量端点。不要用已有广角全景图估算毫米尺寸；现有照片只够选择结构方向。

## 回填格式

复制下列内容到 `config/measured_px_s7000.json`，未知值保持 `null`，并把照片放入 `piano_img/measurements/`：

```json
{
  "M01_octave_span_mm": null,
  "M02_total_keybed_width_mm": null,
  "M03_clear_depth_left_center_right_mm": [null, null, null],
  "M04_deck_above_white_key_left_center_right_mm": [null, null, null],
  "M05_front_edge_note": "",
  "M06_flatness_note": "",
  "M07_control_exclusion_ranges_from_A0_mm": [],
  "M08_eye_view_photo": ""
}
```
