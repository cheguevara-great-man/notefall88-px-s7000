# 练习分析与本地历史

NoteFall 不把“成绩”压成一个无法解释的百分比。每个判定保留为语义事件，再从同一事件流计算页面指标和历史记录。这样界面、导出文件和自动测试使用同一套定义。

## 事件与会话

一次非空会话包含：

- 乐谱名称、原始文件 SHA-256 内容身份、练习模式、声部、速度倍率、移调半音数和可选 A–B 范围；
- 正确音：MIDI 音高、实弹力度、谱面目标力度、目标时间、声部，以及实时模式下的有符号时序差；
- 错键：实际 MIDI 音高、力度和当时谱面时间；
- 漏键：目标 MIDI 音高、声部和目标时间；
- 开始/结束时间、墙钟时长、聚合指标和被安全上限丢弃的事件数。

复位、切换模式/声部/循环/移调或自然完成会结束当前非空会话。只打开乐谱、拖动设置但没有演奏或漏音，不生成空历史。

## 指标定义

| 指标 | 定义 |
|---|---|
| 准确率 | `命中 / (命中 + 错键 + 漏键)` |
| 时序差 | `实际 Note On 时间 - 目标起点`；负数偏早，正数偏晚 |
| 平均时序误差 | 所有实时命中的 `abs(时序差)` 算术平均 |
| P95 时序误差 | 绝对时序误差从小到大排列的 nearest-rank 95 百分位 |
| 拍点偏置 | 有符号时序差算术平均；用于判断整体偏早或偏晚 |
| 力度波动 | 所有命中 Note On 力度的总体标准差 |
| 力度基准偏移 | 所有带目标力度命中的 `实弹力度 - 目标力度` 平均；用于识别整台琴或演奏者普遍偏轻/偏重，不直接惩罚相对强弱轮廓 |
| 力度轮廓分 | 至少 4 个目标样本且谱面目标标准差至少 4 时计算；先移除会话级力度基准，再组合目标/实弹 Pearson 正相关（60%）与基准校正后的平均绝对残差（40%），限幅到 0–100 |
| 时值覆盖分 | 至少 4 个完整松键样本；对每音取 `min(踏板释放后的发声时长 / 谱面目标时长, 1)` 后平均。只惩罚声音过早消失，不把可能合理的踏板延长冒充错误 |
| 无踏板释放精度 | 至少 4 个未由 CC64 延长的样本；以实际按键时长与目标时长的对数比例计算，±15% 作为满分容差，半长/双长附近降至 0 |
| 提前收音率 | 发声时长不足目标 80% 的完整样本比例；进入复盘时间轨和弱点巡回 |
| 踏板延长 | 同时报告由踏板延长的音符数与 `发声时长 - 物理按键时长` 平均值；在缺少可靠踏板记号时不评价“踩得对不对” |
| 和弦展开宽度 | 只对乐谱起点相同、无漏音且至少两个唯一琴键都有实时 `timingMs` 的完整和弦取 `最晚落键 - 最早落键`；相邻琶音不合并，残缺和弦不产生虚假好成绩 |
| 谱面踏板 | MusicXML `pedal` 与 `sound damper-pedal` 解析为踩下、松开、换踏和半踏目标；CC64 阈值边沿与连续深度在 ±450 ms 内一对一匹配，误差按练习速度换算成真实毫秒；A–B 每遍独立判定，至少两个目标才发布综合分 |
| 和弦整齐度 | 至少 4 个完整和弦样本；展开不超过 30 ms 为满分，30–120 ms 线性降到 0，同时报告平均值、P95 与超过 70 ms 的松散和弦数 |
| 双手同步 | 同一跨手和弦内取 `右手平均落键 - 左手平均落键`；正值表示右手晚，负值表示左手晚。至少 4 个跨手样本才发布 0–100 同步分 |
| 最长连续命中 | 按事件顺序计算；错键或漏键会中断连续段 |
| 难点键 | 按每个 MIDI 音高汇总错键与漏键，先按错误次数、再按错误率排序 |

等我弹与跟随我没有外部播放时钟，因此不会伪造节奏精度或和弦同步分；它们仍统计准确率、力度、连续命中和难点键。

## 可视化复盘与趋势

- 进行中的练习以及最后完成的一次练习都生成 24 段时间轨与 88 键热区：绿色为命中，黄色为力度轮廓偏差、提前收音、松散和弦或踏板时机偏差，红色为漏音、错音、漏踏或多余踏板动作集中的位置。时间段提示会列出时值覆盖、提前收音、和弦展开、双手先后与踏板命中/偏差；点击任何时间段会把它精确设为下一轮 A–B，这是从统计回到可执行练习的桥梁。
- 每条历史记录可重新打开为同一种复盘。当前乐谱的内容 SHA-256 相同，才允许从历史时间段建立循环；乐谱不同仍可阅读历史，但按钮被禁用，绝不把旧曲目的秒数套到新曲目上。
- 进步轨迹最多显示同一内容身份的最近 12 次练习。准确率、绝对时序误差、有效力度轮廓、时值覆盖和和弦整齐度分别取最早与最新各最多三次的平均作比较；少于两次时只展示数据、不声称有进步。绝对时序误差变小，其余分数变大才记作正向改善。
- 瀑布流的 `✓`、`×`、`!` 是逐键、短暂的即时判定提示；其目的是让演奏者在不低头看统计卡片时发现问题，并不替代已保存的事件记录。

## 小节重新开始

MusicXML/MXL 五线谱或分屏视图会显示播放顺序的小节轨；反复后的同一书写小节仍作为不同播放 occurrence 保留。一次点击选择 A、第二次点击建立包含两个端点的整小节循环。若 A–B 未开启，可点击“从 A 开始”结束当前非空会话，并从该小节开始全新的判分会话。

此跳转不是简单改变动画时钟：实时 matcher 会从目标位置重置游标，不把前面跳过的音符累计成漏音；Wait/Follow 也会定位到该位置的下一个和弦。A–B 开启时显式禁用任意小节跳转，避免已筛选的循环和弦集与新的全曲位置混用。

## 存储、容量与隐私

- 历史使用独立 IndexedDB，最多保留最近 500 次；超限自动删除最旧记录。
- 单次最多保留 20,000 个事件；若极端长练习超过上限，会累计 `droppedEvents`，不会无限占用内存。
- JSON 导出信封带 `product`、`version` 和 `exportedAt`，便于以后迁移；当前版本为 2。
- 历史不会自动离开手机/平板/电脑，不含 Wi-Fi 密码、原始乐谱文件、USB 描述符或设备标识。
- 清除浏览器站点数据会删除历史，因此长期保存应定期导出 JSON。

## 自适应教练

教练只比较原始文件 SHA-256 完全相同的乐谱，最多使用最近 20 次记录；两份同名但内容不同的乐谱不会串曲。版本 1 的旧记录没有内容身份，仍可查看和导出，但不会在当前已知内容身份的乐谱中被猜测性合并：

1. 在谱面时间轴上扫描 4–12 秒窗口，漏键权重为 2、错键权重为 1；综合错误量、错误率、证据量和错误在窗口中央的程度，选择最值得重复的 A–B 段。
2. 分别计算有明确声部的左右手错误率；差距不足 10 个百分点时保持双手，避免用很少的数据武断拆手。
3. 准确率低于 70% 时建议“等我弹”并降一档；准确率或平均绝对时序未稳定时维持/降低实时速度；若音高和拍点已稳定但力度轮廓低于 60%、时值覆盖低于 75%、释放精度低于 60% 或和弦整齐度低于 65%，先降 5% 定向修正；这些指标没有反证时才允许升速。
4. 页面显示使用了多少次练习、多少个事件、历史准确率、可用的力度/时值/释放/和弦/双手分和低/中/高置信度。弱点巡回会把连续提前收音变成 `时值覆盖 ≥85%` 关卡，也会把松散和弦变成保持实时模式的 `和弦整齐度 ≥80%` 关卡；100% 音高准确率不能绕过表达或同步门槛。没有当前曲目的证据时不生成建议。

算法是确定性的规则系统，不宣称医学、教育学或机器学习结论；所有理由都能由导出的事件复算。

## 跨曲目今日练习

曲库面板会把单曲教练提升为跨曲目队列。它只使用原始文件 SHA-256 完全一致、没有 A–B 循环且判定事件达到目标音数 60%（至少 4 个）的记录；局部刷分、同名异谱和只练几个音不会被算作整曲掌握。

- 最近三次完整记录按 55% / 30% / 15% 加权；准确率是主轴，实时拍点与可用的力度、时值、和弦、谱面踏板分作为补充，缺失的表现力轴不会被当成零分。
- 综合掌握低于 70% 时约 6 小时后优先重练，低于 82% 时隔天重练；稳定记录连续出现后按 1、3、7、14、30、60 天延长复习间隔。
- 每次最多显示三首到期曲目，薄弱曲优先于普通复习，普通复习优先于新曲；若今天没有到期项，只显示最早到期的一首并允许提前练。
- 每一项显示来源清楚的掌握度、预计分钟数和安排理由；点击“开始”打开原始曲目和练习面板，不产生云账号、遥测或不可解释的机器学习分数。

## 自动验证

纯函数测试用固定事件验证拍点偏置、平均/P95、力度基准/轮廓、Note Off/CC64 分离、同音重触发、时值覆盖/释放、和弦分组边界、双手方向、连续命中和难点排序；`fake-indexeddb` 测试验证持久化顺序和版本化导出。真实浏览器回归用目标 `[40,60,80,100]` 与一致 `+10` 的实弹样本验证“轮廓 100% / 基准 +10”，用四个完整目标时值验证“覆盖 100% / 释放 100% / 未检测到踏板延音”，并用四个 20 ms 跨手和弦验证“和弦 100% / 右手晚 20 ms”，同时检查 390×844 页面无横向溢出、历史面板可滚动且不会遮住关闭按钮。
