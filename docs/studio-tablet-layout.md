# Studio 平板布局

NoteFall Studio 的主力现场视口是放在谱架上的 3:2 横屏平板。当前实机目标为用户的 Xiaomi Pad 7 Ultra（16 英寸、3200×2136、275 PPI，实际宽高比约 1.498:1）；布局不绑定商品名、物理英寸或单一像素宽度，而按浏览器实际 CSS 视口和宽高比匹配，因此 Android 的显示大小、DPR 或浏览器工具栏变化不会让规则失效。在 2× DPR/显示缩放下，该面板对应 1600×1068 CSS px，这就是自动化使用此视口的原因。

## 3:2 工作台规则

当横向 CSS 视口至少 1000 px，且宽高比位于 7:5 到 8:5 之间时：

- 演奏页不显示 Core 地址和“独立平板工作台”配置行；连接配置收进“设备设置”，主画面只保留状态胶囊；
- 压缩标题、传输控制、曲目信息和小节导航的垂直占用；
- “五线谱 + 瀑布流”使用约 38% / 62% 的上下分屏，优先保证瀑布流与 88 键琴盘完整可见；
- 五线谱禁止横向溢出，分屏中由演奏光标自动跟随，不出现套娃式横向滚动条；
- 1400 px 以上视口把传输控制保持为单行；
- “专注演奏”仍可一键进入真正的全屏练习表面，并保留退出按钮。

物理屏幕更大不会直接放大按钮；触控尺寸仍保持至少约 38 px，避免谱架距离下界面过度松散。手机和常规 16:9 桌面继续使用各自原有断点。

## 自动验收

`npm run smoke:browser` 会在 390×844、1280×900 和 1600×1068 三种 CSS 视口运行。3:2 检查会拒绝以下回归：

- 页面或谱面出现横向溢出；
- 3:2 专用媒体规则未命中；
- 页面顶部打开时可视化卡片底部超出首屏；
- Studio 分屏留给瀑布流的高度不足 280 px；
- 乐谱导入、谱面 SVG 或当前练习状态在改变尺寸后丢失。

1600×1068 是对 3200×2136 一类面板在 2× DPR 下的代表性 CSS 视口，不是对设备缩放比例的假设。最终实机到手后，只需分别在系统“默认显示大小”和用户日常显示大小执行一次横屏截图验收；不需要重新设计界面。

## 视觉层次

瀑布流在霓虹和柔光主题中包含临近落键光晕、C 音八度导向线、到达线洗光以及命中/错键/漏键粒子反馈。高对比主题刻意关闭装饰性光晕和粒子，保留清晰色块、符号与琴键状态，兼顾长时间练习和可访问性。
