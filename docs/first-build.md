# 第一次装机：用户只需完成的步骤

这份清单是完整文档的最短执行路径。用户不需要设计电路、编译算法或焊板；采购件全部进入最终 88 键版本，没有“一八度测试废料”。

## 不需要购买

- MAX3421E 或其他 SPI USB Host 模块；
- 多条短灯带或额外测试灯带；
- 全长 3D 打印灯带盒/导轨；
- 定制 PCB；
- 第二只 5V 电源；
- 树莓派或专用电脑。

## 已有物品

- Casio PX-S7000；
- 乐鑫官方 ESP32-S3-DevKitC-1-N8R8；
- 带第三供电口的 Micro-USB OTG Y 线；
- 笔记本电脑、手机/平板和 Wi-Fi。

## 一次性采购最终件

按 [BOM](bom.csv) 购买，其中最关键的是：

1. 2m 连续 APA102C 或 SK9822，5V、144灯/m、黑色 PCB、IP30 裸板；最终裁 176 灯（约 1.222m），余料只作同批次维修备件；
2. 74AHCT125 成品模块；
3. 有认证的 5V/5A DC5521 电源和 3A 带座保险丝；
4. USB-A 公转 USB-B 公打印机线；
5. H5、H7 两根 5V/GND Micro-USB 供电线；
6. Micro-Fit 4P、XT30、20AWG 电源线、26AWG 信号线、两只 1000µF/10V 电容和两只 100Ω 电阻；
7. 3-5片拉伸移除式无痕固定条；可选 0.8mm 黑色 PET 载体。

## 把焊接一次性交给卖家

将以下三个文件直接发给淘宝线束店、灯带卖家或手机维修店：

- [逐线制造表](harness.csv)
- [生产线束图](wiring-harness.svg)
- [代工消息模板](vendor-order-template.md)

要求卖家完成灯带裁切、首尾注电、DIN/CIN、两只电容、100Ω 电阻、Micro-Fit/XT30 和 H5/H7，逐线蜂鸣与极性检查后发货。用户不焊开发板，也不需要定制 PCB。

## 收货后的五步

### 1. 只烧录 ESP32

电脑接开发板 `UART/USB-to-UART` 口，按 [烧录说明](flashing.md) 写入固件和 LittleFS。手机应看到 `NoteFall-88` 热点并能打开 `http://192.168.4.1`。首次密码是 `notefall88`；进入后立即在“设备维护”修改它，确认诊断显示“已修改默认密码”。

### 2. 只验证钢琴 USB

暂不接灯带。按 [ADR-001](decisions/001-native-usb-host-and-vbus.md) 连接 H5、H7、Y 线和打印机线。打开设备诊断，确认：

- PSRAM 约 8MiB；
- NVS 显示“正常”；
- 复位原因为 `power-on`；
- 钢琴连接后出现 VID:PID 和 MIDI IN 端点；
- 弹中央 C 后 MIDI 包计数增加。

这一屏截图是第一次必须回传的证据。如果没有枚举，只检查接线和日志，不接灯带扩大变量。

### 3. 台面连接灯带

断电后接 Micro-Fit、XT30 和灯带；不要先贴到钢琴。装 3A 保险，首次以 10% 亮度依次测试 A0、C4、C8。确认方向、颜色、无闪烁、无自行复位，诊断无 `brownout`/`watchdog`。

### 4. 无电纸条试装

剪一条 12mm 宽纸条，在 C4 附近模拟灯带：底边约高于自然白键面 2-3mm、正面朝演奏者，不盖红毡。缓慢按压相邻黑白键到全行程，纸条不得接触键帽。完成后再做 24 小时无痕胶兼容测试。

不确定方向时直接对照 [裸灯带剖面光路图](optical-installation.svg)：灯带竖直贴在钢琴自带黑色立面上，不是朝上平放，也没有琴键侧打印盒。

### 5. 正式贴装和自动验收

灯带断电时贴到黑色固定立面，完成 A0/C4/C8 三点和 88 键校准，再按网页“安装向导”逐项完成证据。最后执行 30 分钟温升、端到端压降、断网/拔线急停和 120fps 延迟测试。

## 暂时不要做

- USB 未枚举前不要接灯带；
- 台面灯带未通过前不要贴琴；
- 12mm 纸条未通过前不要正式粘贴；
- 功能和温升未通过前不必打印控制盒；
- 不得为了“试一下”跳过 3A 保险、公共地或 H7。

这样每一步只增加一个变量，失败时不需要拆整机，也不会产生专用测试废件。
